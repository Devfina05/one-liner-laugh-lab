One short funny line answering a prompt, like the excuse a robot vacuum gives after eating a sock. The funniest, most original line wins.

The program writes a single deadpan excuse to `/output/entry.txt`:

> The sock entered my dustbin voluntarily. I have the suction logs to prove it.

## Run it

```sh
python3 main.py
```
